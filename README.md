# FIR Sahayak — AI-Powered e-Police Desk

Multi-Lingual FIR Summarization System with Local Case Database using React UI.

## Overview
FIR Sahayak is an offline-ready AI system for FIR intake, OCR, summarization, and multilingual translation.

## Features
- FIR Upload & OCR (Tesseract)
- AI Summarization (Qwen2.5-1.5B-Instruct, fine-tuned)
- 12-Language Translation
- Natural Language Search
- Advanced Filtering
- Local SQLite Database
- React + Bun Frontend

## Tech Stack
- Frontend: React + Bun
- Backend: FastAPI (Python)
- OCR: Tesseract
- Summarization: Qwen2.5-1.5B-Instruct
- Database: SQLite
- Deployment: Docker-ready / Offline
